# Artist's Official Website 

This is an official website for the artist Darian Bailey, designed and developed by Tiia Lehikoinen.

Its production website will be found at the address: https://www.darianbaileymusic.com/ once it is in its production version state.

Current version: v0.1
Current environment: development
Release type: production relase

## Content
The website will contain the following main pages:

- Frontpage
- About
- Shows
- Music
- Shop
- Photographs
- Contact

The website serves as the artists portfolio and main place for key information about who they are, where they can be seen, what they have produced and how to contact them.

## Tech used

- HTML
- CSS
- JavaScript
- SVG
- Locally stored Google fonts

## Responsive design

The website uses responsive web design and is designed to work both on mobile and desktop screen sizes. Responsive layouts and media queries are used to adapt the content to different viewport sizes.

## Browser testing

The website has been tested with: 
- Chrome
- Edge

## Accessibility

The website uses semantic HTML elements, keyboard-accessible navigation, normal text contrast checked for a minimum contrast ratio 4.5:1 and alternative text for relevant images.

## Development

For further developing:

1. Clone the repository: *https://github.com/TiiaLehikoinen/artist-website.git*

2. Open the project folder in VS Code and run the site using local development server such as Live Server.

## Deployment

The production version will be hosted using a commercial web hosting service; __Louhi__.
The contents of the project will be uploaded to the web server's public web directory.
The domain (__darianbaileymusic.com__) will be configured to point to the hosting server.

## Updating the website

1. Make and test changes locally.
2. Commit changes to Git and push to GitHub.
3. Upload the updated files to the production web server.
4. Verify the production website.
